# Simtrak Solutions Website

This project is a complete responsive website for Simtrak Solutions built with HTML5, CSS3 and vanilla JavaScript.

## Run the website

Open `index.html` directly in a modern browser, or start a local server from this folder.

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Main files

```text
index.html
css/style.css
css/animations.css
css/responsive.css
js/main.js
js/animations.js
js/menu.js
js/form.js
assets/logo/
assets/clients/
WIP/
```

The contact form validates all fields and prepares a WhatsApp enquiry addressed to the verified Simtrak WhatsApp number.

More implementation notes and pending content confirmations are available in the `WIP` folder.
